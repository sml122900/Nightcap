# 정체성 재정의: 도파민 루프의 출구 → 숏폼 콘텐츠 박물관

## Problem

기존 정체성("평점 앱"이 아니라 도파민 루프의 출구)은 밤 정리 세션(스와이프로 끝나는 피드)은 잘 설명하지만, 왜 낮에 캡처를 쌓는지, 그렇게 쌓인 보관함이 유저에게 어떤 가치인지는 설명하지 못했다. 릴스방/단톡방에 재밌는 콘텐츠를 공유해도 그 방은 보통 일주일이면 대화가 죽고, 콘텐츠는 그 안에 묻혀 다시 찾을 수 없게 된다는 관찰에서 출발 — 반면 그 콘텐츠 자체는 일주일 뒤에도 종종 다시 생각난다. Nightcap의 공유시트 유입(W3-2)이 사실상 "친구에게 보내는 대신 나에게 보내기"라는 걸 재확인하면서, 이 관찰을 정체성 문단에 반영할 필요가 생김.

## Action

- PROJECT.md 최상단 정체성 문단을 "숏폼 콘텐츠 박물관"으로 갱신. "도파민 루프의 출구"는 폐기하지 않고 밤 정리 세션 한정 정체성으로 스코프를 좁혀 유지.
- 낮(수집)=박물관에 전시물을 모으는 행위, 밤(정리)=출구(무한 피드 손맛이되 반드시 끝남)로 두 정체성이 코어 루프(§1)의 낮/밤 구분과 자연스럽게 대응되도록 함.

## Result

- 보관함(§4 "나중")의 존재 이유가 "정리하고 남은 부산물"이 아니라 "그 자체가 목적(다시 꺼내보는 아카이브)"으로 명확해짐 — 향후 보관함 UX(메이슨리, 공유 카드 등) 의사결정 시 이 우선순위를 기준으로 삼을 것.
- 정체성 문구 변경 외 기능/스펙 변경 없음.
